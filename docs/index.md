# Hevo Provider

The Hevo provider manages [Hevo](https://hevodata.com) Pipelines, Destinations and the objects
each Pipeline replicates, through Hevo's API. It works with Terraform and OpenTofu.

## Example Usage

```terraform
terraform {
  required_providers {
    hevo = {
      source = "hevoio/hevo"
    }
  }
}

# Prefer the HEVO_ACCESS_KEY and HEVO_SECRET_KEY environment variables to writing the keys here.
provider "hevo" {
  region = "us"
}
```

## Authentication

The provider authenticates with your team's API access key and secret key. Set them in the
`HEVO_ACCESS_KEY` and `HEVO_SECRET_KEY` environment variables rather than in configuration.

Set `region` to your team's Hevo region, or `HEVO_REGION`. Use `host` (or `HEVO_HOST`) only for a
host that is not a region.

## Schema

### Optional

- `access_key` (String) The team's API access key. Defaults to the HEVO_ACCESS_KEY environment variable.
- `host` (String) The API host, used instead of region, for example http://localhost:9080. Defaults to the HEVO_HOST environment variable.
- `region` (String) The Hevo region of the team: one of asia, au, eu, eu2, in, us, us2. Defaults to the HEVO_REGION environment variable, then us.
- `secret_key` (String, Sensitive) The team's API secret key. Defaults to the HEVO_SECRET_KEY environment variable.
- `skip_plan_time_validation` (Boolean) Skip checking connector configs against each connector's schema during plan, for example to plan without network access. Mistakes then surface at apply.
